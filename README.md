# 智能伴游隐私与安全

项目为景区伴游设备提供能力、风险与游客授权的共同口径。`domain.json` 记录设备能力、风险等级和授权动作。

`core.py` 是位于设备与业务服务之间的控制平台：

- **独立授权与最小权限**：游客对定位、语音、影像、日志分别授权/限制/撤回；设备按行程领取会话，仅获得行程所需且已授权的能力。
- **风险驱动导航**：施工、拥堵、极端环境、走失事件按风险级别（信息提示 < 路线调整 < 停止前进 < 紧急求助）决定导航策略；每次建议都留存所依据的风险信息与授权版本，可经 `/recommendations` 查询。
- **离线轨迹合并**：离线包联网后先校验设备密钥签名与轨迹合理性（坐标、时间戳、速度），异常包隔离不入库；同一离线包重复上传幂等，只生成一份游览日志。
- **缓存失效与删除回执**：授权撤回或到期后，相关会话立即失效，派生的轨迹与日志被删除并开具删除回执（`/receipts`）。
- **家庭同行**：任一成员对某范围不同意时，共享设备不下发该能力，已发放会话同步失效。
- **设备密钥轮换**：旧密钥在宽限期内仍可校验离线包签名，逾期提交的包被隔离。
- **受限审计**：审计员可见全量流水；运营人员仅见脱敏视图，且其查看行为本身被记录。

运行 `python3 service.py --check` 检查基础配置，执行 `python3 -m unittest -v` 验证服务身份与平台行为；后端启动后提供 `/health` 及上述控制接口（见 `service.py` 模块文档字符串）。
